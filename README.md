# 注意力主权协议

**Attention Sovereignty Protocol · v1.1.0 · 中文公开草案 · MIT**

> 让 AI 承担可委派的工作，让人把注意力留给方向、创造与判断。

一套可阅读、可复制、可修改的人机协作协议。通过明确目标、减少无效打断、控制流程复杂度和验证交付物，让 AI 的产出真正转化为成果。

它由 Markdown 文档、提示词与模板组成，无运行依赖。你可以在一次对话、一个项目或个人工作流中使用，不需要先搭建多智能体系统。

**English overview:** A Chinese-first, tool-agnostic protocol for human–AI collaboration. It helps people retain control over goals, attention, priorities, and acceptance while delegating execution. This repository contains editable guidance and templates, not an executable agent or a monitoring service.

## 适合解决什么问题

- AI 生成很多内容，但阅读、比较和验收的负担越来越重。
- 搜集资料和优化流程耗时很多，主要交付物却迟迟没有完成。
- 普通进展频繁打断深度工作，真正的风险反而被淹没。
- 工具、智能体、指标和审批越加越多，协调成本超过收益。

本协议提供可调整的工作约定，不承诺经过科学验证的效率增益，也不替代平台权限、专业判断或现实责任。

## 三步开始

1. 阅读 [智能体宪章](AGENT.md)，了解目标与授权边界。
2. 将 [工作流](SKILL.md) 和它引用的文档提供给你的 AI 工具，或在可读取本仓库的项目中指定这些文件。
3. 复制下面的任务简报，开始一个具体任务；结束后按完成标准验收。

```text
请阅读并按本项目的 AGENT.md 和 SKILL.md 协作。
需要安排通知时使用 HEARTBEAT.md，复盘时使用 REVIEW.md。

主要目标：把现有研究材料整理成可用于决策的一页简报。
交付物：一份含结论、关键依据、反例和未知项的 Markdown 文档。
完成标准：关键结论可追溯到材料；不确定性已标注；没有重复段落。
明确不做：不扩展为完整行业报告，不自动对外发布。
已有授权：阅读所提供材料，整理、改写并保存本地草稿。
需要我决定：材料之间无法消除的关键冲突，以及方向性取舍。

请先删减不必要工作，再推进交付；只在确需我判断时集中提问。
```

只使用普通聊天时，可粘贴相关文档或上传文件，并明确要求采用这些约定。不同工具的自动加载与技能安装规则不同：**文件存在不等于已被加载**。本仓库保留 `AGENT.md` 作为协议文件名，不假定它会作为某个平台的配置文件自动生效。

若宿主支持 `SKILL.md` 技能目录，可将本仓库内容作为名为 `attention-sovereignty-workflow` 的目录交给宿主按其规则加载；须保留相对引用的文件与子目录。本项目尚未提供各平台安装器或完成跨平台运行验证。

## 核心约定

**一个主要成果。** 每个专注周期有明确中心，维护性事务单独安排。

**先合并，再汇报。** AI 执行、去重与核验，人阅读足以做判断的结论。

**授权持续有效。** 同一范围与条件下不反复确认；出现越界或实质风险变化时再升级。

**指标服从成果。** 时长、次数与自动化率是参考，不是必须最大化的目标。

**验证后闭环。** 达到完成标准就停止；未完成则说明阻塞或停止条件，不能用草稿冒充交付。

## 如何调整

可以修改通知频率、复盘周期、验收方式和授权范围。优先改动真正影响当前任务的一两项规则，再观察实际结果。

`HEARTBEAT.md` 只约定通知行为，`REVIEW.md` 只约定复盘方式。它们不会自行建立定时提醒、监控活动或发送外部消息；这些能力需要运行环境支持和相应授权。

个人工作日志建议放在已忽略的 `local/` 目录；示例与贡献材料应去除私人信息。忽略规则不能撤回已经提交到 Git 历史的内容。
